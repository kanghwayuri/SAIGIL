# Pleos Connect 앱 설계 가이드

이 문서는 모바일 앱을 Pleos Connect 앱으로 전환하려고 하거나, 처음부터 Pleos Connect 앱을 설계하려고 할 때 필수적으로 고려해야 할 사항을 가이드합니다.

<br>

[주행 안전을 고려한 설계](./01-driver-distraction-guideline.md): 주행 중 운전자 주의 분산을 줄이기 위한 차량용 앱 UX 설계 원칙을 안내합니다.

[지역별 주행 규제 정책](./02-driving-restiction-policy.md): 차량 상태와 지역 규정에 따른 주행 규제 판단 기준 및 앱 기능 허용 범위를 안내합니다.

[앱 카테고리](./03-app-category.md): Pleos Connect 앱 카테고리의 정의와 카테고리별 주행 중 기능 제약 및 예외 허용 범위를 안내합니다.

[앱 구조 및 동작 모델](./04-app-structure-screen-model.md): Pleos Connect 차량용 앱의 멀티 윈도우 화면 구성, 화면 방향·크기 대응 및 포그라운드·백그라운드 동작 설계 원칙을 안내합니다.

[하드웨어 접근 정책](./05-platform-api-architecture.md): Pleos Connect 하드웨어 접근 정책과 주행 중 네트워크 대응 전략을 안내합니다.

[SDK API 정책](./06-pleos-connect-sdk-api.md): AAOS Alignment 및 하위 호환성 등 Pleos Connect SDK API 정책을 설명합니다.

[API 호환성 및 가용성](./07-api-compatibility-availability.md): Pleos Connect 적용 차량의 API 호환성과 AAOS Vehicle Property 가용성을 안내합니다.

[보안 및 개인정보 보호를 고려한 설계](./08-security-privacy.md): 차량 환경에서의 계정·세션 관리와 개인정보 보호 설계 원칙을 안내합니다.

[성능 및 리소스 효율을 고려한 설계](./09-performance-resource-mgmt.md): 앱 기동·리소스 효율과 오디오 포커스를 고려한 성능 설계 원칙을 안내합니다.
