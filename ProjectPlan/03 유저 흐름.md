## 기본 경로

🛤️

**기본 경로**

W01 역할·조건 확인 → W02 자기 이야기 → W03 수정 → W04 안내 선택 → W05 내용 비우기.

이후 경로는 안내 선택에 따라 달라진다.

- 꺼짐: 앱 개입 없이 이동 → W07 종료.
- 켜짐: W06 안내 대기 → 일반 안내 최대 1회 또는 무음 종료 → W07 종료.

## 단계별 이동 조건

| 단계 | 통과 조건 | 다음 단계 |
| --- | --- | --- |
| W01 시작 | 역할 선택 + 혼자 있음 + 안전한 주차 확인 | W02 |
| W02 자기 이야기 | 실제 장면 입력 | W03 |
| W02B 관심사 | 관심사 + 알게 된 경로 입력 | W03 |
| W03 수정 | 나눌 결과가 공백이 아님 | W04 |
| W04 안내 선택 | 기본 꺼짐 또는 일반 안내 1회 선택 | W05 |
| W05 준비 완료 | 개인 내용 제거 | 꺼짐이면 종료, 켜짐이면 W06 |
| W06 안내 대기 | 지원·권한·필수 신호·오디오 조건 재확인 | 1회 안내 후 W07 또는 무음 W07 |
| W07 종료 | 해당 이동의 추가 안내 없음 | 다음 준비 시 W01 |
| W08 보호 종료 | 개인 내용 제거 | 개인 준비 조건이 맞을 때 W01 |

## 관심사 보조 경로

W02 → 기존 입력 제거 → W02B → W03.

자기 이야기로 돌아오면 관심사 입력도 제거한다. 관심사 경로는 주 흐름과 별도로 완료·재사용을 집계한다.

## 입력 오류

필수 항목이 없으면 같은 화면에서 필요한 항목을 안내한다. 잘못된 입력을 보완하기 위해 사건·감정·출처를 만들어 넣지 않는다.

## 준비 중 종료

⏸️

**준비 중 종료**

사용자 중단 / 페이지 숨김 / 주행 제한·상태 불명 → 입력·결과 제거 → W08.

환경이 나아져도 이전 내용을 자동 복원하거나 재개하지 않는다. 다음 준비는 역할부터 다시 선택한다.


## 차량 안내 상태

대기 → 후보 조건 확인 → 오디오 포커스 요청 → 재생 직전 재확인 → 일반 문장 1회 → 종료.

- 출발 직후·회전·제동·정체·내비·통화: 보류하거나 후보 취소.
- 필수 신호·권한 없음, 연결 손실: 무음 종료 또는 기능 비활성화.
- 재생 중 방해·포커스 손실: 즉시 중단 요청 후 종료.
- 도착·경로 취소·기회 없음: 무음 종료.
- 종료 뒤 늦은 이벤트 수신: 재생하지 않음.

정체·신호대기는 주차가 아니다. 실제 신호 조합과 정책값은 SDK 검증 후 확정한다.

## 실제 대화

이야기를 시작할 시점과 길이는 사용자가 정한다. 앱은 상대의 말·감정을 수집하지 않고 대화가 시작됐는지 자동 판정하지 않는다.
