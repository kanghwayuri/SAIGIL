- 필수: 첫 버전에 포함한다.

## 입력 기준

- 실제 장면: 1~300자, 공백만 입력 불가.
- 내 느낌·생각 / 내 선택 / 남은 생각: 각 300자 이내, 선택.
- 관심사 / 알게 된 경로: 각 1~200자.
- 수정 결과: 1~1,500자.

이는 와이어프레임 기획 기준이다. 기존 개발 개인 준비 모형은 두 입력 필수·각 400자 기준으로 다르므로 실제 앱 구현 전 통일해야 한다.

## 안내 기준

🔈

**안내 기준**

일반 안내 예: “아까 떠올린 내 이야기를, 편할 때 나눠도 좋아요.”

- 자기 이야기 원문·상대 정보·역할을 읽지 않는다.
- 출발 전에 켜고 끄며 기본값은 꺼짐이다.
- 조건을 충족하지 못하면 안내하지 않는다.
- 안내 중단 후 자동 재개·반복 권유하지 않는다.
- 속도나 시간만으로 안전하다고 판정하지 않는다.
