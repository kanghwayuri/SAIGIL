# 시나리오

1. 프로필 생성
    1. 앱 실행
    2. 입력 모드 선택
    3. 프로필 생성(장소 등)
    4. 정보 입력
    5. 종료
2. 화제 거리는 따로 있는 상황, 그러나 대화를 어떻게 시작할 지 모르는 경우
    1. 앱 실행
    2. 추천 모드 선택
    3. 운전자 및 동승자 프로필 선택
    4. 주제 말하기 or 맥락 말하기 선택 → 주제 말하기 선택
    5. 주제 입력(STT)
    6. 입력된 주제를 어떤식으로 풀어갈 지 추천
3. 현재의 맥락만 입력, 그 동안 저장해 두었던 화제 거리 중에서 맥락을 바탕으로 추천
    1. 앱 실행
    2. 추천 모드 선택
    3. 운전자 및 동승자 프로필 선택
    4. 주제 말하기 or 맥락 말하기 → 맥락 말하기 선택
    5. 맥락 입력(STT)
    6. 입력 받은 맥락을 바탕으로 저장된 주제들 중에서 화제 거리를 추천해줌
4. 교통 상황에 따른 능동적인 추천
    1. 앞으로 길게 주행을 해야 하는 상황(e.g. 고속도로 진입) / 정체 구간 진입
        1. 저장된 주제들 중에서 추천, 유행하는 화제를 추천, 밸런스 게임 등의 가벼운 오락거리 제시
5. 함께한 길에 남기기
    1. 앱 실행
    2. 함께한 길에 남기기 모드 진입
    3. 입력 예시
        1. 대화가 원활했나요?
        2. 새로 발견한 관심사가 있나요?
    4. 프로필 간 관계 데이터를 업데이트
